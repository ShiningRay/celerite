## 2026-11-25：无 Ruby 快路径的负向矩阵与 L164 闭合复审（task-261）

### Oracle 与边界

- 兼容 oracle 为同一二进制、同一项目快照、同一环境下 `CELERITE_FAST_PATH=0` 的 lock/install 结果；逐项比较退出码、stdout、去除 bridge stats 行后的 stderr，以及项目/安装树中每个目录项的大小与 SHA-256。仅 `.celerite/cache` 允许因内部失效而不同。
- 本机 RubyGems ABI oracle：`C:\Ruby40-x64\lib\ruby\4.0.0\rubygems.rb:506-511`（`ENABLE_SHARED == "no"` 时 extension API 追加 `-static`）与 `:906-907`（ruby API 取 target rbconfig 的 `ruby_version`）。本机 rbconfig 为 `ruby_version="4.0.0"`、`ENABLE_SHARED="yes"`。
- task-265 释放端口 8765 后，首辅已补跑 Bundler 4.0.24/2.7.2 的 `lock-noop`/`install-rerun` 命令级差分；本项仍只声明这两条无变化路径与参考对齐，不以 compat 路径对齐冒充完整矩阵的参考对齐。

### 实现收口

- `src/celerite/runtime_facts.cr` 新增本机推导的 `ruby_api_version`、`extension_api_version`；共享构建两者相同，静态构建 extension 为 `<ruby_version>-static`，缺失/未知构建模式保持 Unknown。
- `src/celerite/lock_fast_path.cr` 的共享信任门要求锁文件平台恰为当前本机平台；新增任一其它平台都保守回退。`complete_facts` 传入两组新鲜 ABI 视图。
- `src/celerite/fast_path_store.cr` 的运行时记录要求 16 位小写十六进制 credential namespace 且精确相等，不再接受空值通配；`decision` 依次核对 `ruby_api_version`、`extension_api_version`、`rbconfig_ruby_version` 三组新鲜事实；`record_from` 拒绝冲突或本地 ABI 视图未知的写入。
- 未新增 Ruby 可执行文件摘要、默认 gem 路径摘要或环境指纹字段；未条件化 `validate_runtime`，未重写命令输出。

### 负向矩阵

| 类别 | 覆盖 | 判定 |
| --- | --- | --- |
| 开关与冷启动 | `CELERITE_FAST_PATH=0`、unset、非 `1`、eval cache off、冷缓存 | 与 compat 全量对齐；热路径四计数器精确为 0 |
| bridge 故障 | 热命中使用坏 `CELERITE_BRIDGE_SERVER` | lock/install 均 `procs=0 rpc=0 req_bytes=0 resp_bytes=0` |
| 项目与 DSL | Gemfile、evalchain、项目 gemspec 增改、动态 DSL | 回退 compat，stdout/stderr/exit/tree 对齐 |
| 锁与平台 | 锁缺失/修改、CHECKSUMS 空项、新增平台、PATH source | 回退 compat；新增平台不再误命中 |
| 缓存与记录 | 缺记录、格式错、JSON 损坏、空 namespace、runtime 未知 | 回退 compat；腐败记录不产生用户可见差异 |
| ABI 与 runtime | 独立篡改 ruby/extension ABI，并同步重封 record+fingerprint+digest | 新二进制回退 compat；旧二进制反绿 |
| 插件 | plugin 声明、root 非空、hooks；空 root | 非空/声明/hooks 回退；空 root 仍可命中 |
| 安装物化 | installed specification 缺失、gem 目录缺失、native extension 目录/`gem.build_complete` 缺失、InstalledIndex 损坏 | 回退 compat；marker 缺失而目录仍在亦回退 |
| 输出影响开关 | groups/frozen/deployment/shared/force-ruby/clean/cooldown/app-cache/local 等 | 保守回退 compat |
| 默认 gem 路径 | rbconfig 无法推出且 `GEM_HOME` 未设 | `default_gem_dir=Unknown`，不允许命中 |

矩阵实现位于 `spec/m8_fast_path_matrix_support.cr`：每个负例从同一归档恢复两次，分别运行 compat 与 enabled，避免前次运行污染后次状态。
