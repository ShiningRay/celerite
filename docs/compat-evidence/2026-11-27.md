## 2026-11-27：generic-ruby 锁平台 exact-set 门与 Ubuntu lock hot 修复（task-284）

- GitHub Actions run `45957802760` 的 Ubuntu/Bundler 4.0.24 artifact `15179078945` 已下载并读取：`diagnostic-artifact/fast-path-gates-artifacts/lock-fast-hot-debug.stderr:1` 为 `fast-path: lock miss (platforms)`，第 2 行为 `bridge: procs=1 rpc=2 req_bytes=156 resp_bytes=1825`。这是实测 reason，不是由计数推断。
