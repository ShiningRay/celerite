## 2026-11-23：install 回填空 CHECKSUMS 条目的可行边界（task-140）

### oracle

上游 `spec/lock/lockfile_spec.rb:1682`「fills empty CHECKSUMS entries when not frozen, even if every gem is already installed」要求 `install` 在非 frozen 下把锁里空的 CHECKSUMS 条目补成 `sha256=<hex>`。本机取不到该例的参考 oracle 原文：宿主 Ruby 4.0.6 缺 `sinatra`/`artifice`（`spec/support/artifice/helpers/compact_index.rb:3` 报 `cannot load such file -- sinatra/base`），且该例的 `system_gems "myrack-0.9.1", gem_repo: gem_repo2` 在本机未落盘（`.upstream-specs/v4.0.24/bundler/tmp/2.1/gems/` 下只有 `base` 与 `remote1`，无 `remote2`、无 `system`），故该例判为环境族。改用离线差分夹具与手工沙箱取得两侧逐字输出。

本轮结论：**参考 `install` 对空 CHECKSUMS 条目的回填只来自索引（compact index）的 checksum**；从已装包字节算 sha256 的路径只属于 `lock --add-checksums`，`install` 不经过。

### 参考锚点

- `bundler-4.0.24/lib/bundler/fetcher.rb:185`：`source.checksum_store.replace(es, es.checksum)` —— 索引解析期把摘要写进 checksum store，是 `install` 期回填的唯一来源。
- `bundler-4.0.24/lib/bundler/definition.rb:190-200` `setup_domain!`：仅当 `options[:add_checksums] || (!options[:local] && (install_needed? || @locked_spec_with_empty_checksums))` 时才 `sources.remote!`。
- `bundler-4.0.24/lib/bundler/definition.rb:973-1010` `check_lockfile`：`checksum_store.empty?(s)` 的条目收进 `empty_checksums`，末尾置 `@locked_spec_with_empty_checksums`。
- `bundler-4.0.24/lib/bundler/source/rubygems.rb:180-214`：`download`/`install` 遇 `installed?(spec)` 提前 `return`，故**已装 gem 不触发安装期的 `register(spec, installer.gem_checksum)`**，安装期注册无法填补该条空 entries。
- `bundler-4.0.24/lib/bundler/definition.rb:564-583` `#add_checksums`：`Gem::Package.new(spec.source.cached_built_in_gem(spec))` + `Checksum.from_gem_package` —— 从包字节算 sha256 的唯一路径。
- `bundler-4.0.24/lib/bundler/cli/lock.rb:70`：`definition.add_checksums if options["add-checksums"]` —— 上述包字节路径的**唯一**调用点。
- `bundler-4.0.24/lib/bundler/lockfile_generator.rb:69-76`：`definition.resolve.map { |spec| spec.source.checksum_store.to_lock(spec) }` 写出 CHECKSUMS 段。

### 实现位置

- `src/celerite/resolution.cr:1035-1037`：`file:` 源有意留 nil 摘要以保持 parity ——

  ```
  1035:           # Parity: the reference only records per-gem checksums from remote
  1036:           # API sources; file:// indexes install without them.
  1037:           checksum = remote.starts_with?("file:") ? nil : entry.checksum
  ```

- `src/celerite/resolution.cr:2455-2465`：写锁时组装 CHECKSUMS，取值顺序 `installed || existing.try(&.checksums.first?) || spec.checksum`；`:2461` 的 `!c.checksums.empty?` 使空条目不参与 `existing` 查找，故空条目原样写回裸行。
- `src/celerite/resolution.cr:356-380` `compute_checksums_from_installed`：从已装/缓存包字节算 `sha256=<hex>` 写入 `@install_checksums`。
